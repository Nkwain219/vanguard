# Vanguard

A comprehensive enterprise management solution built with Flutter and Firebase. Vanguard streamlines human resource and operational workflows, featuring attendance tracking (with geofencing and selfie verification), employee management, task coordination, leave and salary request handling, and financial tracking.

## Core Features
- **Employee & Volunteer Management:** Complete lifecycle handling for staff.
- **Attendance Tracking:** Sophisticated attendance system featuring automated geofencing and selfie verification.
- **Workflow Automation:** Seamlessly request and manage employee leaves, salaries, and daily tasks.
- **Financial Module:** Built-in wallet management, deposit tracking, and transaction history.
- **Offline & Reliable:** Robust offline support, allowing attendance and project management without an active internet connection.
- **Cross-Platform:** Built natively for iOS and Android using Flutter.

## Technology Stack
- **Frontend App:** Flutter & Dart
- **Backend Infrastructure:** Firebase (Authentication, Cloud Firestore, Cloud Storage)
- **Architecture & Ecosystem:** Provider, GetIt (Dependency Injection)

## Getting Started
1. Clone the repository to your local machine.
2. Ensure you have the [Flutter SDK](https://flutter.dev/docs/get-started/install) installed.
3. Run `flutter pub get` to install all dependencies.
4. Set up your `.env` file according to `.env_template` (ensure your API and Firebase variables are in place).
5. Run the application via `flutter run`.
